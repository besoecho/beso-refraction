# 折光 · beso-refraction

给 SillyTavern 聊天楼层配图的小插件。默认手动生图，按钮固定在酒馆导航栏下方。图片保存在当前酒馆账号的服务器目录中。

## 安装试用版

在酒馆「扩展 → 安装扩展」填写仓库地址 https://github.com/besoecho/beso-refraction.git ，分支填写 **dev/refraction**。

也可以登录 GitHub 下载开发分支 ZIP，解压后把含有 manifest.json 的目录放进酒馆的 data/<账号>/extensions/beso-refraction/，刷新酒馆。酒馆可以直接加载这些文件。

## 第一张图

1. 点小房子进入「生图连接」，填连接名称、地址、API Key、模型和尺寸，点「保存并使用」。OpenAI 兼容渠道通常填写以 /v1 结尾的地址，也接受完整的 /images/generations 地址。
2. 打开聊天，等 AI 回复完成，点小房子右边的图片键。已有 draw 标签时直接生图，否则调用已安装的小海螺提取并注入。小海螺的输出模板需要包含一对 `<draw>…</draw>`。🐚 按钮单独打开小海螺面板。
3. 新图出现在对应回复底部。点标题收起，左右按钮或左右滑动切图，点图片看原图。点小房子，再选「相册」，可以筛选角色或聊天、多选下载和删除。
4. 需要每条新 AI 回复自动出图时，在折光「设置」开启，并在小海螺关闭它自己的自动提取。折光执行中再次点生图键可取消等待。渠道已接受的任务可能继续运行和计费。

## 生图连接

连接下拉框切换当前使用的配置。「接口识别与连接方式」里可以修正识别结果。多个地址各存一套。API Key 单独保存在当前浏览器的本地存储，同一台设备下次打开仍可用。换设备需重新填写。获取模型读取模型目录；测试连接只检查服务响应。这两项都不会提交生图任务。

| 渠道 | 地址和必填项 | 连接测试 |
| --- | --- | --- |
| OpenAI 兼容 | API 基地址、模型、尺寸 | HEAD 检查 models 地址，获取模型使用 GET |
| NovelAI | image.novelai.net 的 HTTPS 地址、模型、尺寸 | 只检查服务根地址 |
| ComfyUI | 服务根地址、API 格式工作流 JSON | 读取 system_stats |
| RunningHub | 服务根地址、工作流 ID、nodeInfoList 的 JSON 数组 | 只检查服务根地址 |
| 自定义 HTTP | 完整 POST 地址、JSON 请求模板 | 只检查服务根地址 |

模板可用 {prompt}、{model}、{width}、{height}、{seed}。例如自定义接口的模板可以写成 `{"prompt":"{prompt}","width":"{width}","height":"{height}"}`。适配器接收图片二进制、url / b64_json 字段或 data 数组中的同名字段。ComfyUI 需导出 API 格式工作流，把正向提示词字段改为 {prompt}，并包含保存图片的输出节点。

默认直连。HTTPS 酒馆访问 HTTP 服务时会选用酒馆代理。模型列表或 ComfyUI 连通测试遇到网络错误时会尝试代理并在成功后勾选该选项，点保存后生效。酒馆服务器需支持该代理，且从服务器能访问目标地址。若出现跨域问题也可自行切换。查询超时可重试一次。会创建付费任务的请求失败时，由用户决定是否再次提交。

## 图片与备份

设置中的「导出备份」生成 ZIP，包含连接、开关、原图、提示词和楼层索引。「导入备份」合并记录，已有图片跳过，同编号连接和折光设置恢复为备份版本。API Key 字段不会写入备份。聊天记录由酒馆另行备份。

- 原图在酒馆账号目录的 user/images/beso-refraction/，索引、提示词和连接配置在 settings.json。楼层及 Swipe 标记随聊天保存。备份整个酒馆账号目录可一起保留这些数据。
- 同一账号换设备后刷新酒馆可加载已保存的相册。和其他酒馆设置一样，两个已打开的客户端同时修改索引可能覆盖设置。
- 多选下载生成 ZIP，单张下载保存原图。确认删除会移除服务器原图和相册记录。删除聊天后仍可从「全部图片」访问曾经生成的图片。
- 首次加载会添加一条仅用于 AI 回复显示的酒馆正则「折光 · 隐藏楼层提示词」。原始楼层和提示词保持可读取。卸载后可在酒馆正则列表自行删除这一条。
- 小海螺联动参照 2.48.1 的页面控件。更换输出标签或升级小海螺后，先用一条回复测试。遇到系统消息排在最后、提取目标不确定时，会停在提取阶段并提示。

## 验证

Node.js 24 可运行 `node --test tests/channels.mjs`，通过模拟响应验证五种渠道、提示词解析和重试。安装 Python Playwright 和 Chromium 后，运行 `python tests/smoke.py` 可在本机模拟酒馆页面检查主要交互。也可用环境变量 CHROMIUM 指定浏览器可执行文件。两种测试都使用本地数据，无需真实渠道密钥。
